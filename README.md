# МойБот · MyBot

**[Русский](#русский) · [English](#english)**

> 🌐 **Язык интерфейса: только русский** · **Interface language: Russian only**

Личный ИИ-агент на Python: видит экран и управляет ПК, работает на локальных моделях Ollama. С веб-интерфейсом и набором «навыков». Предшественник [Ульвара](https://github.com/Vobank/Ulvar).

A personal Python AI agent: sees the screen and controls the PC, powered by local Ollama models. Has a web UI and a set of "skills". Predecessor of [Ulvar](https://github.com/Vobank/Ulvar).

---

## Русский

### Что это
Агент, который умеет «смотреть» на экран и действовать на ПК по задаче. Онлайн-режим: зрение + управление. Всё локально через Ollama.

### Возможности
- 👁 Зрение (понимает экран/скриншоты)
- 🖱 Управление ПК (файлы, окна, действия)
- 🧩 Навыки (расширяемый набор)
- 🌐 Веб-интерфейс
- 🔑 Хранилище паролей (vault)

### Требования
- Windows 10/11, Python 3.12
- Ollama + локальные модели (в т.ч. vision)

### Запуск
- `Запустить бота.bat` — агент
- `Запустить веб.bat` — веб-интерфейс

---

## English

### What it is
An agent that can "look" at the screen and act on the PC for a task. Online mode: vision + control. All local via Ollama.

### Features
- 👁 Vision (understands the screen/screenshots)
- 🖱 PC control (files, windows, actions)
- 🧩 Skills (extensible set)
- 🌐 Web UI
- 🔑 Password vault

### Requirements
- Windows 10/11, Python 3.12
- Ollama + local models (incl. vision)

### Run
- `Запустить бота.bat` — the agent
- `Запустить веб.bat` — the web UI
